## Investigation Findings

### Issue 1: Data Vanishing (ROOT CAUSE IDENTIFIED)

**Evidence:** `package.json` was missing critical dependencies.

**What was missing:**
- `@capacitor-community/sqlite` - Native SQLite plugin for Android
- `@capacitor/local-notifications` - Notification plugin for alarms

**Impact:**
- `bootNative()` in `src/bootstrap.ts` fails on import
- App falls back to `MemoryStore` (in-memory only)
- All data lost on app restart
- Seeded data appears to "come back" because `seed()` re-runs on each launch

**Verification:**
- Console would show: `native boot failed, falling back to memory: [error]`
- User confirmed data disappears between sessions
- User confirmed pre-populated tasks reappear (re-seeded each time)

### Issue 2: Unauthorized Pre-Populated Tasks

**Evidence:** `src/store/memory/seed.ts` contained:

```typescript
// Created on every app launch when store is empty:
- Gym (weekly Mon/Wed/Fri 6:00-7:30)
- Deep work: Spatium (weekly Mon-Fri 9:00-12:00)
- Reading (daily 22:00-22:40)
- Write read.ts, Dentist, Finish normalize.ts (one-off)
- Phase 1 complete, Quant role, Postgrad, The apprentice model (long-term)
- Rewrite it in Rust (abandoned)
- Look into OPFS vs IndexedDB durability, Ask about 2-way diff, Band cross-fade (inbox)
```

**Root cause:** `seed()` runs automatically when `store.listNodes().length === 0`.
Since MemoryStore fallback creates empty store each time, seed runs every launch.
